adsbucks.com admin web interface

all pages of admin interface has a_ prefix.

pages:
	login
	home
	advertisers - the grid of advertisers
		advertiser - the form to edit/add/delete the advertiser and the list campaigns of this advertiser
			campaign - the form to edit/add/delete the campaign and the list of creatives of this campaign
				creative - the form to edit/add/delete the creative
		adv_payments - history list with form to add payment
	publishers - the grid of publishers
		publisher - the form to edit/add/delete the publisher
		pub_payments - history list with form to add payment
	reports - the menu of the reports
		report1 - Campaigns (without SubID)
		report2 - Publishers  (without SubID)
			report3 - Campaigns for each publisher (without SubID)
		report4 - Advertisers (without SubID)
	admins - list of admin user accounts
		admin - form to edit info about specified admin
				and allow/deny some privileges (by 2 select boxes)
	domains - domains list (with number of campaigns assigned to specified domain)
		domain - the form to add/delete/edit domain record
	options - the form to update the values

Pages have the same Header and Footer (includable pages).
There is main menu in the header: Advertisers, Publishers
There is path in the header like: Home > Advertisers > user@test.com > the campaign > creative #3
Grids have sorter and pager functionalities.
Lists have not sorter and pager. Lists have always the same sort order.

Reports pages:


Page 1 - Summary of all Campaigns for time period selected. This page will

have the same data as the Publisher reporting page 1. No SubID information

required.

Page 2 - Summary of all Publishers for time period selected. No SubID 
information required.

Page 3 - Details for each Publishers for time period selected. To access 
this page, there should be a pull down box containing each Publisher. This

page will have the same data as the Publisher reporting page 1. No SubID 
information required.

Page 4 - Details for each Advertiser for time period selected. This page 
will be like the Publisher reporting page 1, but listed by Advertiser.  If

the Advertiser has more than one campaign running, then each campaign will

listed under the appropriate Advertiser. If more than one campaign is 
listed, there will be a sub total for that Advertiser before the next 
Advertiser is listed. No SubID information required.
